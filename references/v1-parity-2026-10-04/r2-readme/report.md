# v1 -> v2 parity, slice r2-readme: compare.py's unsorted strategies

auditor: r2-readme, 2026-10-04. read-only on the tracked tree; probes in this directory.
v1 = `archive/v1/compare.py` (a benchmark script, imported as a module: both `if __name__` blocks are guarded,
so import runs nothing; the second half's `Eps`, `generate_sorted_chunk`, `run_heapq_merge` shadow the first's).

record reading used on both sides, derived from the merge rule `n_start_eps - c_end_eps <= 3` over
`{-2, -1, 0, 2}`: a start is open iff its eps is 2, an end is open iff its eps is -2 (every other eps,
incl. NEG_ZERO=-1, behaves as closed in every touch case: the only pair with diff 4 is start 2 / end -2).
v2 spelling: `MultiInterval.from_pieces([(s, e, s_eps != 2, e_eps != -2), ...])`, or `Builder().add_piece(...)...build()`.
